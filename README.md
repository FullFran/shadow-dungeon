# Mazmorra Sombría

Non-commercial Pokémon fan game prototype: top-down, souls-like real-time combat with Mystery Dungeon-style sprites. The design lives in [`docs/gdd.md`](docs/gdd.md) (Spanish).

Current state (version in `package.json`; what changed in each release: in game under Options → Novedades, from [`src/data/changelog.ts`](src/data/changelog.ts)):
- Main dungeons with eight guardians, and the endless, timed **Eclipse Chasm** (Sima del Eclipse) with daily and free runs.
- The **Sendas** story chapters and the **Sanctum of Oaths** boss trials.
- Online **co-op** for up to 4 players (WebRTC through Trystero, with a Cloudflare TURN relay when a direct link is impossible).
- Optional **accounts** with cloud save, and a global Sima ranking.
- In-game **bug reports** and **patch notes**.

The game runs in the browser and works without an account. The optional online services (accounts, saves, ranking, lore API, TURN credentials, bug reports) are a Go/PocketBase backend in [`server/`](server/README.md), deployed at `sd-api.fullfran.com`.

**Play:** https://www.fullfran.com/shadow-dungeon/

This is a free, non-commercial fan game. Sprites are by the artists of [PMDCollab SpriteCollab](https://github.com/PMDCollab/SpriteCollab); see [`CREDITS.md`](CREDITS.md) and [Legal](#legal).

## Commands

```bash
npm install
npm run dev        # local dev server
npm test           # unit tests (Vitest)
npm run typecheck  # app + DOM-free core
npm run build      # typecheck + production build to dist/
node tools/fetch-sprites.mjs   # re-download sprites and regenerate meta + CREDITS.md
npm run balance    # balance sweep with bots, writes reports/balance/latest.md (~5 min; -- --quick ~15 s)
npm run prove      # beatability proof: finds the walk-only witnesses and solver fights, writes reports/proof/ (minutes; -- --judge re-judges only)
```

### Balance harness

`src/sim` plays the game headless with bots (perfect, average, novice, masher) that see only the screen, on every dungeon × tier × party size (1–4) × seed, floor by floor and in the boss arenas alone, and checks the results against target bands (`src/sim/bands.ts`). `npm test` runs the CI subset (`tests/sim/balance-ci.test.ts`, ~12 s): a fairness invariant (biggest hit ≤ 35 % HP, telegraph floors, wind-ups at once, off-screen threats, unannounced hits) fails it unless it is a recorded known violation; performance bands (clear rates, boss TTK, HP per floor) only warn. To rebalance:

1. Run `npm run balance` on the old numbers; `reports/balance/latest.md` is committed (`latest.json`, every floor result, is ignored).
2. Change the numbers, run it again, diff the report and note the before/after in the task document.
3. When content is fixed, delete its `KNOWN_VIOLATIONS` entry in `src/sim/bands.ts`, so the gate keeps it fixed.

Options: `-- --quick` (CI subset), `-- --seeds=1,2`, `-- --dungeon=<id>`, `-- --tier=<tier>`, `-- --slots` (the perfect and average bots also use the boost before a boss or a crowd and the area move on clusters; off by default, so the committed report keeps measuring the fast slot alone; `reports/balance/four-slots-ttk.md` compares the two), `-- --species=<starter>` (that starter with its default moves) `-- --build=<starter>` (its recommended move-tutor build; `reports/balance/movepools-builds.md` compares them) and `-- --full=<starter> --ranks=2` (its full-investment build with every move at rank +2; `reports/balance/move-progression.md`, and `npx vite-node tools/move-progression-ttk.ts` for the boss TTK comparison). Details in docs/gdd.md §9.

**Beatability proof** (docs/gdd.md §9 "Garantía de que todo se puede pasar"): `src/sim/prove.ts` proves that every spell card of every card boss (and Sima echo) on Normal, Hard and Nightmare can be got through by walking alone, from three starts, on the real engine; that the card framework ends every fight even with zero damage dealt; that every card that can be hurt gives punish windows in its "tu turno" openings, enough for the reference player to empty its segment in time; and a solver bot clears every whole fight on Nightmare. `npm run prove` searches the witnesses (minutes) and stores them in `reports/proof/witnesses.json` with the table in `reports/proof/latest.md`; `npm test` replays them all (`tests/sim/prove-*.test.ts`). A pattern change that breaks a witness fails the tests: run `npm run prove` again (it keeps the witnesses that still hold).

Deploy and releases:
- **Client:** `.github/workflows/deploy.yml` runs the tests, builds `dist/` and publishes it to GitHub Pages on every push to `main` that touches the client (or manually).
- **Backend:** `.github/workflows/server.yml` checks `server/` (gofmt, vet, tests). The backend itself is deployed by hand (`server/README.md`, Deploy).
- **Releases:** follow [`docs/release.md`](docs/release.md): bump the version, add the changelog entry, run the gate (`npm run typecheck`, `npx vitest run --testTimeout=30000`, `npm run build`, `npm run prove`), deploy, then publish the GitHub Release text that `node tools/release-notes.mjs <version>` writes.

## How to play

Open the play link (or `npm run dev` locally). The title screen (Play, Play online, Settings, Credits, Prologue, Town, Shop, Sanctum of Oaths) and every other menu are Mystery Dungeon-style windows with a ▶ cursor: arrows or W/S move it, Enter or Space confirm, Esc goes back, and the mouse works too (hover moves the cursor, click confirms, the ◀ ▶ arrows of a setting change it). The first Play opens a skippable **prologue** cinematic (about 73 s; hold Esc/Enter or click "Skip"; the Prologue entry replays it), then a Mystery Dungeon-style **personality quiz** on a black screen: a voice asks "…Can you hear me?", then six of eight original questions (seeded by `?seed=`), and your nature decides your starter (Mimikyu, Zorua, Litwick or Cubone; accept it or pick one by hand); it becomes your species setting. Settings → Retake the test runs it again. Play then opens the loadout: pick your Pokémon (preselected with the quiz starter) (Mimikyu with Disguise, Zorua with Illusion, Litwick with Flash Fire or Cubone with Battle Armor; sprite, types and passive shown for the one under the cursor), then its four moves, fast, heavy, boost and area (type, power, stamina, shape, cooldown and a short description on each card), then Start; the choice is remembered and also used in shared runs. Settings holds the language, the lock-on options and the volumes (all remembered in `localStorage`) next to the key list. A Crypt run is six floors: two procedurally generated floors (rooms and corridors, sleeping enemies that wake when you come into their room or into sight; floor 1 holds only Poochyena and Gastly, then Duskull drifts after you round the walls with a homing will-o-wisp and Pawniard come in pairs and cut twice, and from floor 4 Golett slams the ground in front of it), the **Sableye** mid-boss on floor 3 (two named spell cards; its slash steals a held item until you hit it back), two more generated floors, and **Aegislash** on floor 6 in a throne room whose pillars stop every shot; at half HP it unsheathes and plays three named spell cards (a ringed spin, an all-round guard that fires fans of blades, and a wall of shadow swords sweeping the room). Candles, graves, braziers and a short lore line on every floor card set the mood. Step on the stairs to go down, no need to clear the floor. HP carries over (each new floor heals 25%), Disguise comes back on every floor. Floors 2, 4 and 5 may be **collapse floors** (25%, 35% and 45%): after a short grace the ceiling falls from the entrance towards the stairs along the walking distance, rubble hurts and pushes you, and escaping shows your time on the next floor's card. Every floor opens with a title card ("Floor 2"), and a Mystery Dungeon-style minimap (top right, Tab to hide) reveals rooms and corridors as you see them; awake enemies chase you around walls. **In-run progression** (all lost when the run ends): defeated enemies give experience (more on deeper floors) and each level adds max HP (healed at once) and damage; the HUD window at the top left reads "Floor 2 · Lv. 5 · HP 52/100" over the HP, stamina and XP bars, Disguise and your held items, and a message log at the bottom left shows the last few events (level up, item equipped, berry eaten, enemy fainted, Disguise broken, collapse warning) and fades them after a few seconds. On entering every floor after the first (boss floor included) you pick one of three **held items** (Choice Band, Leftovers, Quick Claw, Sitrus Berry, Scope Lens, Focus Sash, Shell Bell, Muscle Band, Expert Belt, Bright Powder, Wide Lens, Rocky Helmet), offered by rarity and seeded by run, floor and player; click a card or press 1/2/3. Solo pauses while you pick; a shared run keeps going (the cards sit at the bottom and clicking one never attacks). Items stack up to a cap per item and are listed with their effects in the Esc menu. Some rooms hold an **Oran Berry**: walk over it to heal 20 HP (seen berries show on the minimap). Beating Aegislash opens a second dungeon, the **Misty Forest** (eight floors: Phantump, Pumpkaboo, Foongus, Spinarak and Hoothoot, plus Impidimp who feints and strikes from the side, Shroomish who leaps onto a marked spot and Drifloon who lets go of turning rings of wisps, some in mixed packs; a **Trevenant** mid-boss on floor 4 that slams between three named spell cards: root lanes, a leaf spiral and a closing curse ring; and **Decidueye** on floor 8 in a clearing whose trees stop arrows, three named spell cards and, at half HP, a second phase with an arrow-rain lane sweep, a feather spiral and a shadow stitch with two clones), with its own urgent floor, **Niebla**: the fog closes in until you find the stairs. Beating Decidueye opens the **Flooded Caves** (Cuevas Inundadas, ten floors, its mouth a sunken stair at the end of the Black Lake pier): shallow pools slow anyone who is not a Water type, crystals glow on the walls and water drips from the ceiling; Krabby scuttle sideways and pinch, Remoraid fire bursts down a locked lane, Shellos lob mud, with Zubat, Tentacool, Corphish, Chinchou, Wooper and Clauncher. Its urgent floor, **Inundación**, raises the water until non-Water players wade at half speed. **Lanturn** (floor 5) and **Dhelmise** (floor 10, a phase 2 at half HP) are bullet-hell bosses: named spell cards with bubble rings that leave a gap, spirals, kelp walls with a safe lane, an anchor sweep and a riptide that surfaces under you; the wreck's hull and rocks stop the bubbles. Clearing the Flooded Caves opens the **Toxic Swamp** (ten floors: toxic pools that poison you if you wade in rather than roll, the **Gas tóxico** urgent floor whose cloud spreads from the entrance and drains HP but never the last point, Venipede that roll and bounce, Salandit that dash through leaving smoke, Skrelp that snipe with ink, the roster's poison species, the **Salazzle** mid-boss on floor 5 and the guardian **Nihilego** on floor 10, an Ultra Beast with bullet-hell spell cards, safe pockets to reach and a second phase at half HP). The deeper half of every dungeon also brings **evolved forms** of its regulars (Mightyena, Haunter, Gengar, Dusclops and Bisharp in the Crypt; Breloom, Drifblim, Morgrem, Noctowl and Ariados in the forest; Golbat, Kingler, Octillery and Crawdaunt in the caves; Arbok, Skuntank, Weezing, Muk and Toxicroak in the swamp; Houndoom in the Eclipse Chasm only; all of them in the Chasm from the late floors of their dungeon's stratum): same tell as their line, one more move, more poise, fewer of them per room, and they lead their line's groups (docs/gdd.md "Evoluciones"). Roots, glowing mushrooms, fallen logs, shrines, fireflies, drifting mist and a lore line on every floor card set the mood; on some floors a wandering spirit light leads to a hidden cache of Oran Berries. On hard and nightmare every forest enemy has an extra trick and both bosses an extra card and longer combos (`src/data/forest-tricks.ts`); a few positional attacks (Trevenant's roots, Decidueye's arrow rain) are marked `pierceRoll` for the coming rule that a roll does not save you from them. The **Eclipse Chasm** (Sima del Eclipse) is open from the start: an endless, timed dungeon in the spirit of Zero Isle. A clock starts at 8:00 (it only stops while a solo run is paused), each floor down adds time (40 s, shrinking with depth) and every fifth floor holds an echo that adds more when it falls (a scaled guardian, Aegislash, Trevenant, Decidueye, Dhelmise or Nihilego, on 5, 15, 25...; the chasm's own bullet-hell boss, the **Eclipse Echo**, on 10, 20, 30..., one more named spell card each time, two of them positional, and denser, quicker and titled «Eclipse Echo · III» on every encounter; and from floor 22, on every floor ending in 2, a procedurally generated **Herald of the Eclipse**: a seeded Touhou-style boss with 3-5 named spell cards, each its own HP segment and timer, layered bullet patterns whose every card is proven fair by simulation before it can be played, a phase 2, an original name, epithet and epigraph, and a short intro cutscene the first time you meet it; clearing a card in time without being hit pays Pokémonedas, and the town notice board counts the heralds met); at 0:00 the eclipse swallows the floor and the run ends as a score. Its look changes every ten floors (Crypt, Forest, Flooded Caves, Toxic Swamp, then from floor 41 the abyss: rock islands over a void under a growing eclipse), rooms stay small but deeper floors bring tougher enemies (the Flooded Caves' and Toxic Swamp's enemies join the pool deeper down, glowing elites with a trait, mixed squads), and some floors hold an event (time crystal, treasure vault, merchant echo, eclipse altar pacts, ambush, monster nest, monster house, wave room, an unkillable hunter; harder tiers make them more frequent and Nightmare adds a wave); each floor starts with 3 s of grace on the clock. Elites are one system on every dungeon: the tier's chance on the regular dungeons, and in the chasm the larger of the tier's chance and the depth ramp, with traits tough, frenzied, swift, volley, armored and enrage. Pure mode: level 1, no items, no shop upgrades. Its entry card offers the **daily challenge** (a seed from the UTC date, the same layout for everyone that day) or a free run; scores (deepest floor, then time left) go to a local top 10 shown on the end screen and the town notice board; it pays half the usual Pokémonedas. With more than one dungeon open, a dungeon select follows the loadout (the town's waystone lists them too); floor 1 opens with the dungeon's title and the playing track ("♪ title"). Losing all HP shows the defeat screen; beating a guardian shows the victory screen; both lead back to the town and show the floor reached, the run seed, the level, the items held and the **Pokémonedas** earned (in any dungeon; Sableye, Trevenant, Lanturn and Salazzle pay half a guardian). Add `?seed=123` to the URL to replay a seed (the same seed gives the same floors and the same collapses); on the dev server `?floor=2` also starts on that floor, `?bossHp=0.45` starts its enemies at that share of their HP (Aegislash's phase 2), `?card=2` starts a spell-card guardian on that card (0-based; Aegislash and Decidueye fight with spell cards from Normal: HP segments with a timer, a declaration between cards, a capture reward for going through one unhit; see the GDD; it also starts a herald on that card), `?dungeon=misty-forest` (or `flooded-caves`, `toxic-swamp`) runs that dungeon without unlocking it, `?clock=30000` starts the Eclipse Chasm's clock there (`?nearEvent=1` starts a chasm floor beside its event), `?boss=1234` (with `&floor=32`) fights that seed's herald, `?spawn=koffing,grimer` starts solo on a test arena with those enemies awake (any species with a behaviour, up to 12; the 14 species of the experimental roster, `EXPERIMENTAL_ENEMIES`, are listed in the GDD's "Plantel experimental" and roam only the Eclipse Chasm for now), and `?screen=run` with `&dungeon=` starts a run straight away, `?screen=dungeons|endless|eclipse|loadout|quiz|prologue|settings|credits|online|lobby|victory|defeat|town|shop|shrine` opens that screen straight away (for screenshots; the lobby preview uses a tab-local channel, not Trystero, and `&guest=1` joins it from a second window).

**Difficulty** (docs/gdd.md §9): Easy, Normal, Hard and Nightmare. Easy keeps the balance as it was (only the two positional attacks below are new on every tier). Solo, pick it on the moves screen above Start (remembered); in an online room the host picks it in the dungeon mouth or waystone window and the guests see it in the room window. Harder tiers raise enemy HP and damage moderately, shorten telegraphs (never below a readable floor of 75 % and 280 ms), shorten enemy cooldowns, add tinted **elites** (tough or frenzied), shrink the roll's i-frame window and raise its cost (Hard, Nightmare), limit solo floor restarts (Hard 1 per floor, Nightmare none) and pay more Pokémonedas (×1.3, ×1.7, ×2.2). They never add enemies; instead Hard adds new attacks and longer combos (Aegislash's feint fourth blow, Pawniard's third cut, Poochyena's pack howl, twin wisps, second casts and repeats for seven Sima species) and Nightmare adds extra spell cards (Aegislash's Judgement, a fourth Glint for Sableye). **Positional attacks** (a white and violet pulsing border, a violet "!" and their own warning sound) cannot be rolled through on any tier: walk out of the area (Aegislash's shadow wall, Sableye's gem burst; Midnight's spin from Hard). Records (best floor and clears per dungeon) and the Sima's top 10 are kept per tier; the town board and the end screen show the tier.

**Town** (last entry of the title menu; `?screen=town` on the dev server, `&map=ruinas|mirador|crater|lago|cienaga&tile=x,y` to open another map): a small walkable world under the eclipse, built from Ninja Adventure tiles (CC0); the title music keeps playing. Walk with WASD, the arrows or the touch joystick; E, Enter or Space (or "Hablar") talks to the gacha stall (Mimikyu), the upgrade shop (Poochyena) and the storyteller (Gastly, who tells one piece of the legend per talk), or reads the notice board (this device's records: best crypt floor, runs, victories and best level, written at the end of every solo or hosted run); Esc closes a dialog or goes back to the title. The hub, Dusk Haven, is one of six maps joined at their edges with a short fade (docs/gdd.md §3, "El mundo"): the Road of Ruins (the Crypt's mouth), Lookout Pass (a bridged chasm, the eclipse at its biggest, the Misty Forest at the treeline), the Eclipse Crater (the mouth of the Eclipse Chasm, open from the start) Black Lake Hamlet, a second village with a fisher, a flame keeper and a seer, and east of it the Mire of the Broken Sky (the Toxic Swamp's mouth, a Croagunk hermit and a fallen crystal). Walking into a dungeon's mouth asks "Enter …?" (or says why it is sealed) and goes on exactly like Play (prologue and quiz first if they are still due, then the loadout); the waystone by the hub's east road lists every open dungeon as a shortcut. Statues, a road sign and an idol say more after each guardian falls; harmless Pokémon wander about. The gacha still says "Coming soon"; Poochyena opens the upgrade shop. The stone altar on the hub's south lawn is the **Sanctum of Oaths** (Santuario de los Juramentos, also the last title entry): *Reflections* re-fight any boss you have beaten, on any tier, in its own room at the level expected on its floor with no items or upgrades (heralds you met too, by seed), and *Trials* chain bosses back to back (Guardians: Aegislash, Decidueye, Dhelmise, Nihilego; Every Oath: all eight in dungeon order) with HP carried over plus a 30% heal between fights. It keeps the best time, cards captured and an "Unscathed" flag per boss, trial and tier; reflections pay nothing and each trial pays once per tier. Solo only. On the dev server `?screen=shrine&view=gauntlets` opens it and `&trialSkip=1` starts a trial with its first boss already beaten.

**Co-op scaling** (docs/gdd.md §8, provisional, `src/data/party-scaling.ts`): the party size is the players present when a floor is entered (fainted ones count; someone leaving mid-floor changes nothing until the next floor), counted on every peer and sent by the host. With 1 / 2 / 3 / 4 players bosses, mid-bosses and echoes have ×1 / 1.6 / 2.1 / 2.6 HP, other enemies ×1 / 1.25 / 1.4 / 1.55, boss fights hit ×1 / 1 / 1.1 / 1.15 harder and bosses take ×1 / 0.6 / 0.4 / 0.3 of the stagger, so four players cannot stunlock them; the enemy count never changes. From two players a boss keeps one target and turns to the next player every 6 s once it has attacked, or at once towards a player who deals it 8 % of its HP behind its back, never mid wind-up; from three players Trevenant, Decidueye, Sableye, Dhelmise and Salazzle add one more area card they already know. Solo is unchanged.

**Meaningful encounters** (docs/gdd.md §3 "Encuentros con sentido", provisional, `src/data/encounters.ts`): fewer enemies that matter. Every floor species has a role (brute, skirmisher, ranged, swarm, controller, support) with a threat cost, and each room spends a budget on roles: 0 to 3 enemies, two roles up to Normal and three from Hard, gunners and controllers at the back of the room, some rooms empty. About 40 % fewer enemies per floor in every dungeon; each pays more XP (by role) and 1.65 Pokémonedas instead of 1, so a floor is worth about the same. Some groups follow a crowned **leader** (more from floor 2 and deeper): more HP, double XP and a rally cry that heals its followers and readies their next attack; when it falls brutes and swarms reel, skirmishers and gunners slow down, controllers lose its pace. Some floors (never floor 1 or an urgent floor) hold one **mandatory kill**: stairs sealed until the marked enemy falls, a locked stairs room whose key a marked enemy drops, or in the chasm its wave room; a line on screen and the minimap show what keeps the stairs shut, and a gate enemy out of every player's reach for 60 s breaks the gate without its bonus.

**Pokémonedas and the shop** (provisional numbers, docs/gdd.md §11): every run pays Poké Coins into a local save (`mazmorra-sombria.save`, versioned with `migrate()` and `sanitize()`), per floor cleared (by depth), per enemy defeated (more on deeper floors), for escaping a collapse quickly, for beating the guardian and per minute played; a defeat keeps 75%. The HUD shows the coins earned so far ("12 P"), and the end screen lists where they came from and the new balance. In a shared run every player, guests too, earns for themselves. Spend them at Poochyena's stall in the town or from Shop on the title menu: five permanent upgrades (Vitality, Second Wind, Respite, Reflexes, Insight) of three to five levels each, with small increments, applied at the start of every run for every species.

**Move tutor** (docs/gdd.md §4, "Movimientos y maestro"): Smeargle, on the hub's west lawn, teaches each starter the rest of its canon learnset (level-up, TM, tutor and egg moves from PokeAPI, 23–28 moves per species) redesigned for real-time play: drain, recoil, burn and poison as damage over time, high-crit swings, priority, homing stars and a lingering fire vortex, with powers from the games. Every move has a power tier against the best original move of its slot and shape: Basic (the original kits), Advanced (up to ×1.2 effective damage) and Master (up to ×1.4, paid with two real costs such as recoil, a slow wind-up or heavy stamina; some unlock only after clearing the Crypt or the Misty Forest). Advanced moves cost 120–650 Pokémonedas by slot and power, Master ones 450–950. Every known move can be ranked up twice (+10 % damage per rank, shorter cooldowns on boosts), and each rank adds its own designed effect (crit, size, burn chance, a mark that bursts, split shots, a weakened target, lingering zones and aftershocks, extra hits, a boomerang thrown again, chains, super-armor, i-frames, stronger buffs, drain, stagger, homing, a heal: `src/data/rank-effects.ts`), under a hard ceiling of ×1.9. Learned moves and ranks count everywhere, the Sanctum and the Sima's pure mode included; Sima scores record the build. Its window has a Pokémon row and a slot filter (◀ ▶); purchases live in the save (version 2). The loadout lists only learned moves, with the same filter and the recommended competitive build (Smogon sets) under the list. `?screen=tutor` opens it on the dev server; `npx vite-node tools/movepool-tables.ts` prints the per-species tables of the GDD.

Aegislash blocks hits from the front in Shield Forme (the blue arc): flank it. In Blade Forme it attacks in combos and stays open afterwards.

### Online rooms

"Play online" in the main menu: **Create room** makes a 5-character code (no 0/O or 1/I/L) and shows it big with a copy button; **Hide code** masks it for streamers. Friends type it under **Join** (or open the page with `?room=CODE` to prefill it). Up to 4 players; a fifth is told the room is full. The room is the town: everyone appears walking it together (positions sent about ten times a second), with each player's **nickname** over their head and a small room window in a corner (code, hidden while **Hide code** is on, and who is in); Esc opens the room menu (copy or hide the code, leave). The host leads the group by walking into a dungeon's mouth ("Enter …? (the whole group)") or with the waystone; for the Eclipse Chasm the host picks the mode there ("Enter · Daily challenge" or "Enter · Free"). Guests are told only the host can. Everyone plays the host's seed. When a shared run ends (or a solo one: back to Dusk Haven), **Back to town** brings the room back to the town for another run (the host's choice pulls the guests along); late joiners appear in town. The **nickname** (Settings or the online screen; empty means "Player-XYZ") is trimmed, cut to 16 characters and stripped of control and invisible characters, travels in the join message, and replaces the "P2"-style tag over remote players in a run; the end screen lists the party. Peers find each other through public Nostr relays ([Trystero](https://github.com/dmotz/trystero) 0.26, default strategy) and then talk browser to browser over WebRTC. No TURN server is configured, so two players behind strict NATs may not connect. Trystero loads only when you open a room, never in solo play. `?lag=`, `?jitter=`, `?loss=` and `?delay=` work here too. In a shared run, **F3** shows the net stats overlay: role, players connected, round trip per player, snapshots per second and their age (guest), and bytes per second out and in.

### Two tabs together (local development)

Open the game with `?net=local` in two or more windows of the same browser (up to 4 players) and press Start in each: the first one (or the one with `?host=1`) hosts and the others join it; everyone plays the host's seed. Each tab simulates its own player with no wait, the host runs the enemies, and an enemy attack only hurts you if it touches you on your own screen. Remote players show as "P2", "P3"... with an HP bar; a fainted one stays down until an ally stands by them for 3 s (a green ring fills; getting hurt or stepping away starts it again), then gets up with 30 % HP, once per player per floor (not on Nightmare); the run ends only when everyone is down. The host's stairs take everyone down. `?lag=150&jitter=30&loss=0.05` simulates a bad network on what that tab sends, and `?delay=100` tunes how far in the past remote players and enemies are drawn. Tabs opened at the same instant agree on one host (the lowest random id). Remote players' projectiles are drawn on every screen. If the host closes, guests get "The host left" and a button back to the menu. A perfect dodge in a shared run gives the dodger the flash and sound but never slows the enemies for anyone. Every standing player gains the experience of every enemy defeated, each picks their own held items, and Oran Berries are host-authoritative (the first player to claim one gets it). Use separate windows side by side: a browser stops animating a hidden tab, and a hidden host stops the run.

### Connecting, relays and diagnosing a room

Guests appear in a room only once the host has let them in (the host's roster is the room).
- Until then the guest's room window says "Conectando con la sala…".
- After 25 s it explains that the host is not answering: nobody created the room, an outdated game, or a network that blocks direct links.
- Opening a room fetches short-lived TURN credentials from the API (`GET /api/sd/turn`): links try direct first and fall back to Cloudflare's relay. Without the API, co-op stays direct-only.
- A version mismatch names both versions and how to update.
- F3 in a shared run shows the role, admission, RTT and direct/relay per peer.
- "Copiar informe técnico" (room Esc menu and the in-run pause menu) copies a privacy-safe snapshot of the session for bug reports.
- Real-network tests (two browsers on two networks, relay-only, four players): [`tools/coop-net/`](tools/coop-net/README.md); results are tracked in issue #5.

### Reporting a problem

Options → "Reportar un problema" (also in the town Settings and the pause menu): a short form, no account needed.
- It answers with a reference like `SD-ABC123`.
- With "Adjuntar información técnica" on, it attaches the game version, a coarse device summary and the session diagnostics (no IPs, nicknames, emails, tokens or saves).
- Reports are stored privately on the backend. The owner triages them and promotes the real ones to GitHub issues (`server/README.md`, Bug reports).

### Phones, tablets and installing

Touch controls turn on at the first touch (Settings → Touch controls: Automatic, On, Off): a floating joystick in the left half, Roll / Fast / Heavy (hold to charge) / Boost / Area (hidden while their slot is empty) / Lock (tap to lock the enemy in front, swipe sideways to switch target) on the right, Pause and Map at the top right, an on-screen "Atrás" for Esc in menus (the shop too; the end screen uses its own "Back to menu"), and a joystick plus "Hablar" in the town. In the shop a tap on an upgrade shows its effect and a second tap buys it, so a stray tap never spends coins; in landscape the shop and the end screen lay out in two columns to fit a phone. Auto-aim (nearest enemy in a cone in front when nothing is locked) and vibration are settings. Landscape is recommended. The game is a PWA: `public/manifest.webmanifest` (icons drawn by `node tools/make-icons.mjs`) and `public/sw.js`, a versioned service worker registered only in builds, which precaches the app shell, caches sprites, tiles and music as they load, never touches cross-origin traffic (online rooms), and shows "Nueva versión disponible — Actualizar" when a new deploy is waiting. Chrome/Edge/Android get an "Instalar juego" title entry and a one-time banner; iOS Safari gets Share → Add to Home Screen instructions.

### Accounts and cloud save

Optional: guests play exactly as before and the game makes no request. Title or Settings → Cuenta: sign up with email and password, log in, log out, delete the account (its cloud save goes with it; the save on this device stays). While logged in, the whole profile (save, run records, shrine records, Abyss leaderboard, bestiary; settings stay per device) syncs with the cloud like other web games: each browser remembers the cloud revision it last synced, so only-local changes go up (debounced, retried when offline), only-cloud changes come down silently ("Datos de la nube cargados", with Undo), and when both economies moved the player picks "Este dispositivo" or "La nube" from two cards. A new browser gets "Encontramos tu progreso en la nube" with Download or Start fresh (start fresh leaves the cloud alone until you choose). The economy is never merged; achievements, records, leaderboard and bestiary always are. Every replacement keeps a local backup (last 3, restorable, exportable as JSON), only one tab pushes, and local data stays tagged with its account (another account logging in is asked, never auto-merged). Your email is private and only used to log in; there are no analytics and no password reset yet (no outgoing mail).

The API base URL comes from `VITE_API_URL` (default `https://sd-api.fullfran.com`, whose CORS only allows the published site). For local development run the backend from `server/` (`go run . serve --http=127.0.0.1:8090 --origins=http://localhost:5173`) and start Vite with `VITE_API_URL=http://127.0.0.1:8090 npm run dev` (see `.env.example`). Never create test accounts on the production server. Code: `src/adapters/account-api.ts` (fetch adapter), `src/app/account.ts` (session), `src/app/cloud-sync.ts` (decision table, sync state and push loop), `src/app/profile.ts` / `profile-merge.ts` / `cloud-payload.ts` / `backups.ts` / `sync-leader.ts` (profile, merge rules, payload, backups, leader tab), `src/app/account-screen.ts` (screen and wiring). See docs/gdd.md, Cuentas.

## Sound

Sound effects are procedural Web Audio (`src/adapters/audio.ts`), with no sound files: short retro effects synthesised from oscillators, noise and filters, mapped from the core's `GameEvent`s (a pure `soundFor(event)`), throttled per sound and capped in simultaneous voices. Sound starts on the first click or key press, since browsers block autoplay. The menu has master, music and effects volume sliders and a mute checkbox (remembered with the other settings); `M` toggles mute in game; the Esc menu lowers the music.

### Music

Each context has a licensed track (manifest with loop points, licenses and change notes in `src/data/music.ts`; files in `public/music/`): the title, menus and lobby play *Lonely Village*, generated Crypt floors *RPG - Underworld Theme - Loop*, the collapse floor *Determined Pursuit*, the guardian *16-bit - Battle Theme I* (also the Trevenant mid-boss), the Misty Forest floors *Cathedral in the forest* (muffled by a low-pass on fog floors), Decidueye and Nihilego *Boss Battle #2 [Symphonic Metal]*, the Flooded Caves floors *Underwater* (Cleyton Kauffman; muffled on flood floors), Dhelmise *Fairy Boss Battles* (MintoDog), the Toxic Swamp floors *Swamp Theme Loop* (beardalaxy, CC0), and the end screens a one-shot stinger (*Victory* by Umplix, *Game Over Theme II*). A track is fetched and decoded the first time its context plays (a two-entry LRU keeps recent buffers), loops gaplessly between sample-accurate loop points (`AudioBufferSourceNode` `loopStart`/`loopEnd`) and cross-fades over 1.2 s on context changes; stingers stop the loop quickly and play once. Files are Ogg Opus with an MP3 for browsers without Ogg (Safari before 18.4), loudness-normalised to -18 LUFS (stingers -16). If a file cannot be fetched or decoded, the floor music falls back to the original procedural chiptune (A minor, `src/data/audio.ts`; faster on the boss floor) and the stingers to synthesised ones. In a shared run each player hears the music of their own state; nothing goes over the network.

Licenses: CC0 1.0 tracks (Eldritch Grim, Emma_MA, HydroGene, Umplix, Cleyton Kauffman, congusbongus, nene, MintoDog, beardalaxy) and one CC BY 4.0 track (jocolloman), credited with their changes in `CREDITS.md` and `public/music/LICENSES.md`. Credit lines must stay in any redistribution; when a stream VOD is re-uploaded, put the CC BY credit in its description.

## Layout

| Path | What |
|---|---|
| `src/core` | Pure, deterministic simulation (no DOM, no adapters; compiled without DOM typings) |
| `src/sim` | Balance harness on top of the core: bots, headless runner, metrics, bands, report (only tests and tools import it) |
| `src/data` | Typed game data: species, moves, type chart, level curve, held items, coin rules, upgrades, sprite meta |
| `src/adapters` | Rendering, input, assets, audio, storage |
| `src/net` | Co-op netcode: protocol, version gate, host-authoritative session (lobby, admission, runs), interpolation, transports (BroadcastChannel, lag simulator), diagnostics |
| `src/app` | Bootstrap and wiring, the save facade (`save.ts`) and the shop window |
| `src/pwa` | Install invitation rules and service worker registration (the worker itself is `public/sw.js`) |
| `src/i18n` | `es.json` (default) and `en.json` |
| `server/` | Go backend on PocketBase: accounts, cloud saves, profiles, Sima ranking, lore API, TURN credentials, bug reports, backups ([README](server/README.md)) |
| `tools/` | Sprite fetcher, proofs, release notes, phone checks (`tools/mobile/`) and real-network co-op tests (`tools/coop-net/`) |
| `odd/tasks/` | Feature documents (specs, tasks, logs); the backlog itself is in GitHub Issues |
